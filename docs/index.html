Why it exists

True round-robin — even while streaming

Built for the Claude Code CLI and any Anthropic-compatible SDK. All keys from all groups are pooled and load-balanced. Every request gets a different key.

True round-robin

Every request gets a different key. All keys from all groups are flattened into a single global pool. No more burning through one key before touching the next.

Mid-stream aware

Detects error events inside a streaming response before any content reaches you, and silently retries on a working key. You see one clean stream.

Concurrency-aware

Tracks in-flight requests per key and prefers idle keys. Multiple simultaneous requests are distributed across different keys, not piled onto one.

Stall protection

If an upstream stops sending data mid-stream, the proxy aborts after 120 seconds instead of hanging forever. Connect timeouts and slow keys are deprioritized.

Multi-provider groups

Organize keys by upstream endpoint — each group has its own URL and cooldown settings. All keys participate in the global pool regardless of group.

Disable without deleting

Temporarily disable individual keys or entire groups with a toggle switch. Disabled items are skipped during routing and stay off until you re-enable them — no data loss.

Live terminal & dashboard

Color-coded real-time logs in the terminal with request IDs and timing. A pool stats dashboard shows total, active, rate-limited, invalid, disabled, and in-flight counts.

Install on Windows

One command. A desktop shortcut. Done.

The installer clones the repo, installs dependencies, builds the app, and drops a shortcut on your desktop that launches the dashboard in your browser.

1

Install the prerequisites (skip any you already have)

Run in PowerShell. pnpm is enabled automatically by the installer via corepack.
winget install --id Git.Git -e; winget install --id OpenJS.NodeJS.LTS -e
2

Run the one-command installer

Open a new PowerShell window and paste this. It builds everything and creates your desktop shortcut.
irm https://raw.githubusercontent.com/Ns81000/claude-key-pool/main/install.ps1 | iex
3

Open the dashboard any time

Double-click the “Claude Key Pool” shortcut on your desktop — it starts the server and opens the UI at localhost:9999. Add your keys and hit Connect.
http://localhost:9999
4

Update any time

One command pulls the latest version, rebuilds, and relaunches. Your saved keys are never touched.
irm https://raw.githubusercontent.com/Ns81000/claude-key-pool/main/update.ps1 | iex
Manual / cross-platform

Any OS with Node 20+ and pnpm

git clone https://github.com/Ns81000/claude-key-pool.git && cd claude-key-pool && pnpm install && pnpm build && pnpm start
How it works

Every failure mode, handled

The proxy classifies each upstream response and decides whether to rotate, retry, or fail cleanly.

429 (key-level)
Mark key rate-limited, honor retry-after, rotate
429 (IP-level)
Rotate to next key without cooling down the current one
401 Unauthorized
Mark key invalid (auto-recovers after 1 hour), rotate
403 Forbidden
Transient provider error (5-min cooldown), rotate
400 invalid_request_error
Client error (e.g. bad model name) — returned cleanly to client
rate_limit / overloaded / quota
Mark limited, rotate to the next key
SSE error before any content
Silently retry — client sees one clean stream
SSE error after content started
Forward as-is, mark limited so the next request rotates
5xx / network / timeout
Transient — try next key (marked slow); 502 only if all fail
Upstream stalls (120s silence)
Abort the connection and error to the client
All keys exhausted
Return a clean 429 to the client
